    回购定盘利率-历史¶

    start_date str start_date="20200930"; 开始时间与结束时间需要在一年内

    FR001 float64 注意单位: %

    FDR001 float64 注意单位: %
    FDR007 float64 注意单位: %
    FDR014 float64 注意单位: %

    import akshare as ak

repo_rate_hist_df = ak.repo_rate_hist(start_date="20231001", end_date="20240101")
